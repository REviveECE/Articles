# Embedded System Section

This section contains Arduino examples and Proteus projects for:

- 74HC595 and 74HC165 shift registers
- PCF8574 I2C GPIO expanders
- MCP23017 I2C and MCP23S17 SPI GPIO expanders

The original project files and their existing folder structure are preserved. The saved PCF8574 reference link is in `02- PCF8574 (I2C Port Expander)\3-Input and Output\New Text Document.txt`.

Future sections can be added as sibling directories alongside `Embedded System Section` at the repository root.
